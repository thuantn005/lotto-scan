# Phân Tích Dữ Liệu Xổ Số - Nghiên Cứu Xác Suất

Đây là dự án nghiên cứu cá nhân về phân tích quy luật số liệu và phân bố xác suất.

## Mục đích nghiên cứu
- Nghiên cứu phân bố số ngẫu nhiên
- Phân tích tần suất xuất hiện các con số (mục đích học thuật)
- Thử nghiệm xử lý song song với Github Actions

## Công nghệ sử dụng
- Python 3.10
- Pandas, Numpy
- Github Actions để tự động xử lý dữ liệu

## Cách hoạt động
Dự án chạy các tác vụ phân tích dữ liệu theo lịch để xử lý tập dữ liệu lớn (31 tỷ số / batch) phục vụ nghiên cứu thống kê.

## Lưu ý
Dự án chỉ phục vụ mục đích học tập và nghiên cứu, không khuyến khích cờ bạc.
